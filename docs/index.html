01 / 核心能力

简单的控制，
精确的分流。

不用折腾系统级代理，也不用维护复杂的全局规则。AppProxy 把控制权交给你正在使用的应用。

01

每个应用，独立规则

为 ChatGPT、Claude、浏览器或任何 Windows 程序分别选择代理、直连或阻止。

ChatGPT代理→Clash / 7897
Obsidian直连→本地网络
02

不改变你的系统

不创建 TUN 网卡，不修改 DNS、系统代理或路由表。其他应用照常工作。

AppProxy↗目标应用系统保持不变
03

看得见每一次连接

实时查看进程、活动连接、代理地区和延迟，让网络状态不再是黑盒。

从启动那一刻起，
规则才开始生效。

AppProxy 使用本地转发组件，将代理设置精确交给目标应用。你不需要成为网络专家。

01

添加代理

填写 Clash、Mihomo 或其他 SOCKS5 / Mixed 代理地址，一键测试。
